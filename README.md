# ⚔️ Turn Battle

Projeto desenvolvido em **Python** como parte do módulo 2, com foco na criação de um jogo de **combate em turnos**.

O jogador controla um herói que enfrenta um inimigo em uma batalha, utilizando **ataques normais e especiais**. O projeto trabalha conceitos de **Programação Orientada a Objetos**, como **herança, encapsulamento, abstração e polimorfismo**, aplicados à criação dos personagens e suas habilidades.

### 🎮 Funcionalidades

- Batalhas em turnos
- Controle do herói pelo jogador
- Ataques normais e especiais
- Sistema de pontos de vida
- Condição de vitória e derrota
- Diferentes personagens e habilidades

### 🛠️ Tecnologias

- **Python**
- **Programação Orientada a Objetos (POO)**
